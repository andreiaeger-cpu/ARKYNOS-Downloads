# ARKYNOS — downloads para Windows

Este repositório contém somente os pacotes de teste e suas instruções. O desenvolvimento é mantido separadamente.

## Baixar versão de teste

[Baixar ARKYNOS para Windows 64 bits](https://github.com/andreiaeger-cpu/ARKYNOS-Downloads/releases/download/teste-2026.10.21/ARKYNOS-Teste-Windows-2026-10-21.zip)

Extraia o ZIP em uma pasta nova local, abra ARKYNOS-Teste e execute Arkynos-Candidato-R10.exe. Não precisa instalar Python. No primeiro acesso cadastre uma empresa fictícia e seu usuário/senha de teste.

Pacote portátil de teste, sem assistente de instalação. Não substitua a instalação de uso diário. Teste em outro Windows ainda pendente; não é versão comercial definitiva. Use somente dados fictícios. Emissão fiscal e licenciamento comercial dependem de homologação própria.

Os hashes SHA256 estão anexados à Release para conferir a integridade do download.
